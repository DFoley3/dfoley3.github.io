Hypertext Transfer Protocol

Hypertext Transfer Protocol (HTTP) is the set of rules that lets web browsers, apps, and servers talk to each other across the World Wide Web.

Whenever you click a link, load a web page, or send data in an app, HTTP is the underlying system making that exchange happen.

Key Terms

  • World Wide Web: a system of interconnected documents and resources accessed via the Internet, primarily through web browsers.
  • Uniform Resource Identifier (URI): sequence of characters that identifies an abstract or physical resource on the internet.
  • Uniform Resource Locator (URL): a specific type of URI that provides the means to access a resource on the internet.
  • Content Delivery Network (CDN): a network of distributed servers that deliver web content to users based on their geographic location.
  • Multiplexing: the process of combining multiple signals into one signal for transmission over a shared medium.
  • Metadata: data that provides information about other data, such as the title, author, or creation date of a document.
  • User Agent:Any program that communicates with a web server using HTTP. Web Browsers are the primary example.
  • Proxy: a server that acts on behalf of another server, typically for the purpose of routing requests or adding additional functionality.
